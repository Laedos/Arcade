# Arcade

Small browser games, live at https://play.sbdevworks.com.

- **Slingwell**: circle a planet, let go at the right moment, and get caught by the next orbit.
- **Stacker**: drop the sliding block; the overhang gets cut off. Build as high as you can.
- **Mirror Snake**: classic snake, but every fourth apple flips your controls.
- **Lights Out**: each light flips itself and its neighbours. Turn them all off.
- **Four in a Row** (2 players, one screen): take turns dropping discs; line up four to win.
- **Doodle Telephone** (online multiplayer, coming soon): write a prompt, draw what you get, guess what you see, then
  watch every chain fall apart. 2 to 12 players, join with a room code.

```sh
npm install
npm run dev
```
